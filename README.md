# Gabriel Hamel’s Homebrew tap

Prebuilt `wg-launcher` binaries for macOS (Apple Silicon and Intel) and Linux x64.
Rust and Cargo are not required.

## Install

```sh
brew install gabrielhamel/tap/wg-launcher
```

## Upgrade

```sh
brew update
brew upgrade gabrielhamel/tap/wg-launcher
```

Check your installed version with `wg-launcher --version`.
Homebrew owns this installation: `wg-launcher self-update` is disabled and
instructs you to use `brew upgrade` instead. If you previously installed with the
shell installer, remove that older executable from your PATH so your shell uses
the Homebrew copy (`which -a wg-launcher` shows all copies).

## Releases

The formula downloads versioned archives from
[wg-launcher Releases](https://github.com/gabrielhamel/wg-launcher/releases)
and verifies their SHA-256 checksums. It is generated by cargo-dist and updated
by the launcher release workflow through a tap-scoped deploy key.

[CLI documentation](https://github.com/gabrielhamel/wg-launcher/tree/main/crates/wg-launcher-cli)
